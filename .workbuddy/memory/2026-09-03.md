## 生成图片占位(同上 ImageGen,4 张)
- 为首页/产品/传感器/云平台四个关键位生成科技蓝商务风的占位图(约 20–40 积分)。
- Y 盘映射目录对命令行进程只读(Bash touch 权限拒绝,PowerShell Rename 静默不执行,即使 dangerouslyDisableSandbox 仍无法 mv),导致 ImageGen 输出的长文件名无法在工具内重命名为简短名。
- 解决:直接把 markdown 引用改成长文件名(hero 插入到首页 H1 上方;egw-x1 与 sensor-series 替换正文图片;云平台截图正式插入)。
- 各页面注释也同步改为"AI 占位图,需替换时改回简短名"的提示。
- 限制:ImageGen 输出右下角有"AI 生成 WORKBUDD"水印(平台默认添加,无法通过 prompt 关闭)。生产官网建议二次处理(裁剪/付费去水印)或等真实图片到位后覆盖。
- 用户可在 Windows 资源管理器手动重命名以恢复简短路径名(简短名引用约定保留)。
