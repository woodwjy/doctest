    无线智能传感系列¶

    面向设备状态监测与环境监测的无线传感器产品线，免布线安装，适合存量车间改造与广域布点场景。

    产品类型¶

    型号 类型 典型测点 组网方式
    WS-TH10 温湿度传感器 车间 / 库房 / 机房环境 LoRa / NB-IoT
    WS-VB20 振动传感器 电机、风机、泵类设备 LoRa / 4G
    WS-CT30 电流互感器 配电回路电流监测 LoRa
    WS-LK40 水浸 / 门磁传感器 机房漏水、门窗状态 LoRa

    关键特性¶

    • 免布线部署：无线组网，磁吸 / 卡扣安装，单点施工 < 10 分钟。
    • 超低功耗：休眠功耗微安级，标准场景电池续航 3~5 年。
    • 多级组网：传感节点 → LoRa 网关 → 云平台，单网关可接入 500+ 节点。
    • 数据可靠：数据加密传输、本地补报机制，避免信号波动导致丢点。
    • 即插即用：出厂预配对，扫码即可接入 IoT 云平台自动生成资产档案。

    规格参数（以 WS-VB20 振动传感器为例）¶

    项目 参数
    测量范围 加速度 ±16g，速度 0~50mm/s
    采样频率 最高 6.4kHz 可配置
    防护等级 IP67
    工作温度 -30℃ ~ +85℃
    供电 内置电池（续航 3~5 年）
    通信 LoRa / NB-IoT / 4G 可选

    典型应用¶

    • 电机、水泵、风机振动监测与轴承异常预警
    • 医药 / 电子车间温湿度环境合规记录
    • 配电柜温度、回路电流的无线监测
