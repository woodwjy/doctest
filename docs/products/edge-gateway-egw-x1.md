# 边缘计算网关 EGW-X1

面向工业现场的边缘计算网关，向下对接 PLC、数控、仪表等异构设备，向上通过 MQTT / HTTPS 与 IoT 云平台或第三方系统通信。

![EGW-X1 产品图](img/Industrial_IoT_edge_gateway_pr_2026-09-03T10-14-44.png)

## 关键特性

- **多协议接入**：支持 Modbus TCP/RTU、OPC-UA、S7、三菱/西门子 PLC、DL/T645 电表等，内置 100+ 常见驱动。
- **边缘计算**：内置规则引擎与数据预处理，可在本地完成阈值判断、数据清洗与格式转换，降低云端带宽与延迟。
- **断网续传**：离线数据本地缓存，网络恢复后自动补传，保证数据不丢失。
- **远程运维**：支持远程配置下发、固件 OTA 升级与设备诊断。
- **工业级设计**：-40℃ ~ +75℃ 宽温，金属外壳，导轨式安装，支持 9~36V 宽压供电。

## 规格参数

| 项目 | 参数 |

| 无线 | Wi-Fi 2.4G/5G、BLE 5.0 |
| 工作温度 | -40℃ ~ +75℃ |
| 供电 | DC 9~36V |
| 防护等级 | IP30，导轨式安装 |
| 认证 | CE / FCC / RoHS |

## 典型应用

- 产线设备数据采集与 OEE 分析
- 空压机、注塑机等单机设备远程监控
- 配电房 / 泵站等无人值守站点的数据回传
